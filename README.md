## 📊 Ключевые выводы из EDA (Этап 1)

* Распределение энергии имеет сильную асимметрию (правый хвост) из-за мощных приборов.
* Использование среднего арифметического искажает картину — **рекомендуется использовать медиану и метрику MAE** (Mean Absolute Error) для оценки моделей.
* Признак (месяц) полезен, так как помогает выявить сезонность нагрузок (например, в феврале вероятность высоких нагрузок выше, чем в мае).
* Матрица корреляций (использована ранговая корреляция Спирмена, как устойчивая к выбросам) показала базовые взаимосвязи между признаками.

##  Как начать работу над проектом (Инструкция для команды)

1. Склонируйте репозиторий на свой компьютер:
   `git clone https://github.com/altynovamariya-netizen/energy-case.git`
2. Установите необходимые библиотеки (если их нет): 
   `pip install pandas numpy matplotlib seaborn plotly`
3. Перед началом работы над новым этапом **ВСЕГДА** делайте `git pull`, чтобы получить свежие изменения от других участников.
4. Создавайте новые ноутбуки в папке `notebooks/` (например, `02_Preprocessing.ipynb`), сохраняя нумерацию этапов.
